# Paradise Nursery

Paradise Nursery is an online plant shop built with React and Redux Toolkit. Users can browse houseplants by category, add them to a shopping cart, and manage cart items with live totals.

## Features

- Landing page with a "Get Started" button
- Product listing with three plant categories (six plants each)
- "Add to Cart" buttons that disable after a plant is added
- Navbar with Home, Plants, and Cart links
- Cart icon showing the total number of items
- Shopping cart page with quantity controls, delete button, per-plant totals, and a cart total
- Checkout button (Coming Soon) and Continue Shopping button

## Tech Stack

- React
- Redux Toolkit
- React Router (or state management as applicable)
- CSS for styling
